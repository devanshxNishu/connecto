Grow your LinkedIn network, a few careful requests a day

Connecto finds the people you want to meet, writes a personal note for each of them and sends a small number of connection requests every day. It runs on your own computer, in your own browser. Free and open source.

Get started View on GitHub
Read this first. LinkedIn does not permit automated activity, and it can restrict accounts that use automation tools. Connecto keeps the numbers low and stops at the first sign of trouble, which lowers that risk. It does not remove it. Use Connecto only if you accept the risk for your own account.

How it works

1. Find

From the YC startup directory, a CSV file, any web page with profiles, a LinkedIn search, or a list you type.

2. Write

A personal note from your own templates. Optionally, AI adds one checked opening line.

3. Send

A few requests a day, inside hard limits, from your own browser. You read every note first.

Get started

You need Python 3.10 or newer, Google Chrome (or Microsoft Edge) and a LinkedIn account. It takes about 10 minutes. Connecto is developed and tested on Linux; macOS and Windows work but have had less real-world use, so please report anything odd.

  1. Install Connecto

    Open a terminal (on a Mac: the Terminal app) and run these lines one at a time.

    git clone https://github.com/YOUR-USERNAME/connecto.git
cd connecto
python3 -m venv .venv
source .venv/bin/activate
pip install .
connecto doctor
    git clone https://github.com/YOUR-USERNAME/connecto.git
cd connecto
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install .
connecto doctor

    connecto doctor tells you if anything is missing and changes nothing. No Chrome or Edge? Run python -m playwright install chromium once. In every new terminal window, go to the folder and activate .venv again before you use connecto.

  2. Open the setup page

    connecto ui

    A private page opens in your browser. It runs only on your computer (127.0.0.1). Read the risk note and accept it, tell Connecto your first name and what you work on, choose who you want to meet, and write your notes. Prefer the terminal? connecto init asks the same questions.

  3. Sign in to LinkedIn

    On the setup page, press Sign in to LinkedIn. Or run:

    connecto login

    A browser window opens at LinkedIn. Sign in yourself, the way you always do. Connecto never asks for, sees or stores your password. It keeps the signed-in session in its own browser profile on your computer, and connecto logout deletes it.

  4. Collect people and read the notes

    connecto fetch      # collect people from your sources
connecto preview    # who is next, and the note each person would get

    Nothing is sent in this step.

  5. Send the first few, and watch

    connecto run --dry-run    # visits profiles, shows what would happen, sends nothing
connecto run --limit 3    # sends at most 3, after you confirm

    Watch the browser window. If LinkedIn shows a warning or a check, Connecto stops, and so should you for a few days.

  6. Let it run every day

    connecto schedule install
connecto schedule status

    It runs at 10:40 and 18:20 by default (change this in the settings or with --times), only inside your active hours, and collects new people before each run. Keep your computer on and signed in to your user account.

Optional: a personal first line from AI

Connecto works without AI. With a free key from Gemini, Groq or OpenRouter, or a model on your own computer (Ollama, LM Studio), it can add one short opening line to each note. Only a few public facts are sent: title, company, headline, description, industry and tags. Never a name, a link, a location, an e-mail address or a phone number. Every line is checked before it is used, and a line that fails the check is simply left out.

connecto ai providers   # the free and local options
connecto ai key         # save your key in a private file
connecto ai test        # check that it works

Limits that never change

These are ceilings in the code. No setting raises them.

30requests a day at most
100requests a week at most
20requests in one run at most

Connecto stops at the first sign of trouble: a LinkedIn check page, a warning page or repeated errors. It uses no tricks against LinkedIn's checks: no fingerprint changes, no CAPTCHA tools. Your settings, history and browser session stay on your computer, in ~/.connecto. There is no server, no user account and no telemetry. More about safety.

Questions

Is it free?

Yes. Connecto is open source under the MIT License. The AI helper is optional, and it works with free providers or a model on your own computer.

Does it work with a free LinkedIn account?

Yes. Set message.plan to free for 200-character notes or premium for 300. If LinkedIn offers no note box, Connecto sends the request without a note, or stops if you set if_note_unavailable: stop.

Can LinkedIn restrict my account?

Yes. LinkedIn does not permit automation, and nobody can promise that an account stays unrestricted. Keep the numbers low, watch the first runs, and stop for a few days if LinkedIn shows a warning.

Does it send messages?

No. Only connection requests, with an optional short note.

Something does not work

Run connecto doctor first. Then read troubleshooting, or open an issue on GitHub.
